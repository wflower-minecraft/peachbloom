## 🌸 桃花树

> 桃花树并非随处可见。寻找合适的光照与气候，开启桃花云的奇妙旅程。

- **生长条件：** 亮度低于 5 无法生长（桃花树不耐阴）。
- **生成群系：** 大多数主世界地表群系都有可能出现（苍白森林，黑森林，冰相关群系除外），气候越极端概率越小（比如沙漠）。
- **生成数量：** 桃花树最多 3 棵同时存在（最少 1 棵），生成逻辑类似遗迹。

### 🪵 桃花原木

<sub>可燃 · 堆叠上限：64</sub>

- 可合成台阶（可燃，堆叠 64）、楼梯（可燃，堆叠 64）、栅栏（可燃，堆叠 64）、栅栏门（可燃，堆叠 64）、门（可燃，堆叠 64）、活版门（可燃，堆叠 64）、压力板（可燃，堆叠 64）、按钮（可燃，堆叠 64）、木头（可燃，堆叠 64）。
- 被斧头去皮会变成去皮桃花原木（可燃，堆叠 64）。
- **桃木剑合成配方：** 堆叠上限为 1，自带亡灵杀手 1。

  | 合成材料 | 合成栏位置 |
  | :--- | :--- |
  | 桃花原木 | 第二列第二排 |
  | 木棍 | 第二列第三排 |

- 被亡灵生物捡起会使亡灵生物持续燃烧直至其死亡。

### 🍯 桃胶

<sub>堆叠上限：64</sub>

- 会生成在去皮桃花原木上（材质类似 1.21.4 的树脂），可直接采集，享受时运效果。
- 可以直接食用。与牛奶、糖、小麦合成桶装桃胶粥（堆叠 1）。
  - 食用后：生命回复 1，持续 10 秒。
- 3 × 3 合成桃胶块（堆叠 64），性质类似粘液块，具有可燃性。可以食用。

### 🌺 桃花树叶

<sub>堆叠上限：64</sub>

- 放入烟熏炉变成 **干桃花（堆叠 16）**（可燃，非面对生物时可食用）。
- 干桃花可以对生物洒出，对亡灵生物造成少量伤害。
- 和牛奶合成 **桃花奶（堆叠 1）**（使牛奶只删除负面效果）。
- 和蜂蜜瓶合成 **桃花蜜（堆叠 16）**（获得效果：辟邪 10s）。

### 🍑 桃子

<sub>堆叠上限：64</sub>

- 可以食用。放入烟熏炉制成瘪桃干（堆叠 64），提供饱食度增加，类似烤肉。
- 与蜂蜜瓶制成蜜桃罐头。
- 围一圈黄金变成金桃子（堆叠 64），食用后提供以下效果：

  | 效果 | 持续时间 |
  | :--- | :--- |
  | 速度 1 | 60 秒 |
  | 生命恢复 2 | 5 秒 |
  | 抗性提升 2 | 10 秒 |
  | 力量 2 | 10 秒 |

- 放入高炉制成桃花锭（堆叠 64），合成桃花装备、桃花工具（无法合成桃花剑）。属性类似钻石，但耐久堪比金（桃花装备均享受保护 2，桃花工具享受亡灵杀手 2 和时运 2）。

### 🌿 桃树枝

<sub>堆叠上限：64</sub>

- 出现概率极低的掉落物，可以合成 64 个木棍或 8 个桃花原木。
- 可食用，去除所有负面效果并加上以下效果：

  | 效果 | 持续时间 |
  | :--- | :--- |
  | 生命回复 2 | 10 秒 |
  | 力量 2 | 10 秒 |
  | 抗性提升 2 | 10 秒 |
  | 幸运 V | 120 秒 |

- 可以酿造辟邪药水。

### 🛡️ 辟邪效果

> 使亡灵生物攻击拥有该效果的生物时返还其攻击伤害的 10%（类似荆棘），不造成击退。

## ☁️ 桃花云维度

> 一片整体色调偏粉的奇妙天地，由桃树森林、桃花平原与高悬云端的桃花云共同组成。

### 🚪 进入与退出

- 在桃花树下撒干桃花进入，退出方法同理。

### 🌍 维度规则

- 维度纵深取值 **-50 < y < 150**，y = -50 格处有基岩，y < 150 无法放置方块。
- 桃花云维度整体色调偏粉，比如粉色的草方块、石头等。
- 维度内只有 3 个群系：桃树森林、桃花平原、桃花云端。
- 桃花云维度地形生成逻辑类似主世界，但严格遵守生成范围，基岩无法直接接触空气。村庄（主世界平原村庄）较多。

### 🌳 桃树森林

- 桃树森林是由桃花树组成的森林，树的生成不再讲究遗迹生成规律，而是像普通的橡树森林一样成堆生成。

### 🌼 桃花平原

- 桃花平原同主世界的繁花平原，出现村庄概率大。

### ☁️ 桃花云端

- 桃花云端随机生成，位于桃花云维度 y > 70 坐标。
- 此群系由桃花云（堆叠 64，方块，采集后不掉落物品）组成（类似空岛）。桃花云是一片片成团的扁云，只有穿戴桃花靴子的玩家可以自由在上面行走。
- 桃花云上可以种树，并且会刷新敌对生物 **[云簇怪]**。云簇怪移动缓慢，攻击自带漂浮 3 秒和缓慢 1 秒，击杀掉落桃花云。

### 🏘️ 桃花村庄

- 桃花村庄的农作物只有桃花萝卜（堆叠 64），可以合成金桃花萝卜（堆叠 64）（配方类似金胡萝卜，效果也一样）。
- 桃花萝卜可以喂猪，使猪一次生下 2～3 只小猪。
