# 桃花云 Peach Bloom
Fabric 26.3 模组。

## 桃花树
* 亮度低于5无法生长（桃花树不耐阴）。
* 大多数主世界地表群系都有可能出现（苍白森林，黑森林，冰相关群系除外），气候越极端概率越小（比如沙漠）。
* 桃花树最多3棵同时存在（最少1棵），生成逻辑类似遗迹。

---

### 桃花原木（可燃 堆叠64）
* 可合成台阶（可燃 堆叠64） 楼梯（可燃 堆叠64） 栅栏（可燃 堆叠64） 栅栏门（可燃 堆叠64） 门（可燃 堆叠64） 活版门（可燃 堆叠64） 压力板（可燃 堆叠64） 按钮（可燃 堆叠64） 木头（可燃 堆叠64）
  *被斧头去皮会变成去皮桃花原木（可燃 堆叠64）
* 这样合成桃木剑（堆叠1）（自带亡灵杀手1）：
  `[桃花原木]` + `[木棍]` （[桃花原木]位于合成栏第二列第二排 [木棍]位于合成栏第二列第三排)
* 被亡灵生物捡起会使亡灵生物持续燃烧直至其死亡。


### 桃胶（堆叠64）
* 会生成在去皮桃花原木上（材质类似1.21.4的树脂），可直接采集，享受时运效果。
* 可以直接食用。与牛奶、糖、小麦合成桶装桃胶粥（堆叠1）。
  *（食用后）生命回复1 10s。
* 3x3合成桃胶块（堆叠64），性质类似粘液块，具有可燃性。可以食用。

### 桃花树叶（堆叠64）
* 放入烟熏炉变成**干桃花（堆叠16）**（可燃，非面对生物时可食用）。
* 干桃花可以对生物洒出，对亡灵生物造成少量伤害。
* 和牛奶合成**桃花奶（堆叠1）**（使牛奶只删除负面效果）。
* 和蜂蜜瓶合成**桃花蜜（堆叠16）**（获得效果 辟邪10s）。

### 桃子（堆叠64）
* 可以食用。放入烟熏炉制成瘪桃干（堆叠64），提供饱食度增加，类似烤肉。
* 与蜂蜜瓶制成蜜桃罐头
* 围一圈黄金变成金桃子（堆叠64），食用后提供效果：速度1 60s ，生命恢复2 5s ，抗性提升2 10s ，力量2 10s 。
* 放入高炉制成桃花锭（堆叠64），合成桃花装备、桃花工具（无法合成桃花剑）。属性类似钻石，但耐久堪比金（桃花装备均享受保护2 桃花工具享受亡灵杀手2和时运2）。

### 桃树枝（堆叠64）
* 出现概率极低的掉落物，可以合成64个木棍或8个桃花原木。
* 可食用，去除所有负面效果并加上：生命回复2 10s、力量2 10s、抗性提升2 10s、幸运5 120s。
  *可以酿造辟邪药水

### 辟邪效果：使亡灵生物攻击拥有该效果的生物时返还其攻击伤害的10%（类似荆棘） 不造成击退

## 桃花云维度
* 在桃花树下撒干桃花进入 退出方法同理。
* 维度纵深取值-50<y<150，y=-50格处有基岩，y<150无法放置方块
* 桃花云维度整体色调偏粉，比如粉色的草方块，石头等。
* 维度内只有3个群系 桃树森林，桃花平原，桃花云端。
* 维度地形生成逻辑类似主世界，但严格遵守生成范围，基岩无法直接接触空气。村庄（主世界平原村庄）较多。
* 桃树森林是由桃花树组成的森林，树的生成不再讲究遗迹生成规律，而是像普通的橡树森林一样成堆生成。
* 桃花平原同主世界的繁花平原，出现村庄概率大
* 桃花云端随机生成，位于桃花云维度y>70坐标。此群系由桃花云（堆叠64，方块，采集后不掉落物品）组成（类似空岛），桃花云是一片片成团的扁云，只有穿戴桃花靴子的玩家可以自由在上面行走。桃花云上可以种树，并且会刷新敌对生物[云簇怪]，移动缓慢，攻击自带漂浮3s和缓慢1s，击杀掉落桃花云。
* 桃花村庄的农作物只有桃花萝卜（堆叠64），可以合成金桃花萝卜（堆叠64）（配方类似金胡萝卜 效果也一样） 桃花萝卜可以喂猪，使猪一次生下2~3只小猪。
